Этот скрипт непрерывно с заданным интервалом времени собирает ключевые метрики системы, выполняя команды мониторинга памяти, дискового пространства и общей нагрузки. Все полученные данные разделяются временными метками и последовательно записываются в лог-файл, позволяя отслеживать состояние сервера в фоновом режиме.
